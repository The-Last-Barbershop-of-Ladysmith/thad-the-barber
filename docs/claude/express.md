# Express web server

Moved from CLAUDE.md; read it when working in `thad-the-barber-express/` or on how the Angular build is served.

`thad-the-barber-express/` — the Express 5 web server (JavaScript, CommonJS) that App Service runs for the site; the zip deploy is this folder with the Angular build in `public/app/thad-the-barber-ui` (one folder per app, so a later portal can sit beside it; `npm run build:express:<env>` in the UI writes it there, plus `csp-sources.json`, `brand.css`, `fonts.css` (the display and body fonts' `@font-face` rules copied from the built stylesheet, for the error page), `font-preloads.json` (the Latin display and body fonts and PrimeIcons' woff2, which `lib/font-preload.js` swaps for Angular's unused `.eot` preload in every page's head, #243), `shop.json` (name, phone and Square booking URL for the error page, BR-14) `client-routes.json` and `sitemap.xml` (the UI's `INDEXED_ROUTES` under the environment's `siteUrl`, #72) from its post-build hook, `scripts/write-express-files.ts`). `routes/index.js` serves prerendered pages, the app shell for the client routes in `client-routes.json` (the UI's `CLIENT_ROUTES` in `app.routes.server.ts`, which also renders them on the client; a `:param` matches any one path segment; `/book` until #58) and the prerendered `/404` page with a 404 for anything else. The home page also gets its `HairSalon` JSON-LD at request time (`lib/site-data.js` reads the anonymous `/api/shop` and `/api/reviews` from `API_ORIGIN`, reuses a copy for 10 minutes, serves a stale one while it refreshes, retries a failed first read at most once a minute; `lib/structured-data.js` builds and injects it, #71), and only when the prerendered page has a canonical link, which only an indexed environment has; `lib/` holds the per-request CSP nonce, security headers (helmet, `NOINDEX`) and telemetry (Azure Monitor, started from `bin/www` only when `APPLICATIONINSIGHTS_CONNECTION_STRING` is set); `routes/robots.js` serves `/robots.txt` (`Disallow: /` unless `NOINDEX` is `false`, then `Allow: /` plus a `Sitemap:` line at the address of the home page's canonical link; add a page to `INDEXED_ROUTES` when it gets `isIndexed: true`); `routes/health.js` serves `/healthz`. Thrown errors render the themed `views/error.ejs` (`lib/error-handler.js` middleware, ported from `wireframe/site/error.html`: status, request ID = trace ID, shop phone and Square booking link from `shop.json`, own strict CSP, styled by `public/stylesheets/error.css` over `/brand.css`); the stack trace shows only when `NODE_ENV=development`, which App Service never sets. `ERROR_TEST_ROUTE=true` adds `/_test/error?status=` for tests (Playwright's CI server). Tests: `npm test` (Vitest + supertest against a fake build).
